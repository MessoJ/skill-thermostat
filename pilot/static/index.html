Python Practice Study

Before you start

This is a research pilot about how AI help affects learning. You will solve short Python exercises. On some exercises an AI helper is available, on others it is switched off, and which is which is decided by the system. Some tasks are done with no help at all so we can measure what you can do on your own.

We record your submitted code, whether it passed, how you used the helper, and activity in this page (pasting, and switching away from the tab). We do not record anything outside this page. Participation is voluntary and you can stop at any time. Do not enter personal information in the code or chat.

Research-pilot notice: before real participants, this study needs an ethics review and a consent text approved by one. This text is a placeholder.
